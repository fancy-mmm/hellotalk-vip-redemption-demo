HelloTalk TikTok Shop VIP 会员兑换 Demo

使用方式：
1. 直接双击 index.html，可在本机查看静态页面。
2. 发布到 Vercel、Netlify 或公司静态服务器时，将本目录内全部文件上传到站点根目录。
3. 本项目不依赖后端、数据库或构建工具。

文件说明：
- index.html：页面入口
- app.js：交互与演示数据
- email-login.js / email-login.css：官网式邮箱登录弹窗及登录状态演示
- styles.css / theme.css / adjustments.css：页面样式

注意：该 Demo 仅用于需求评审与交互演示，不包含真实登录、会员发放或 TikTok Shop 接口。

邮箱登录演示：
1. 从邮件点击领取，再点击右上角登录或登录并继续。
2. 输入任意有效格式的邮箱，点击获取验证码（仅本地模拟，不发送邮件）。
3. 演示验证码为 123456；其他六位数字显示验证码错误。
4. 登录后返回原兑换页，领取时不再弹二次确认。
5. 左侧“邮箱登录 · 状态演示”可直接查看格式错误、验证码错误／过期、账号未注册、发送失败、登录失败、网络异常。
6. 错误／过期／失败文案是补充演示，不冒充官网实测原文。未注册提示已按仅登录流程移除注册引导。
7. 倒计时 60 秒、演示码 5 分钟有效仅为演示参数，不代表生产环境规则。
